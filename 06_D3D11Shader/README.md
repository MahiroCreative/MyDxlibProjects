# 06_D3D11Shader — DxLib の Direct3D 11 シェーダー教材

DxLib(3.24f)で、Direct3D 11 モードの自作シェーダーを書くための教材です。
公式リファレンスは Direct3D 11 のシェーダー仕様を「非公開」としており、公式サンプルもすべて Direct3D 9 用です。
この教材は、その 2 つを Direct3D 11 用に作り直します。

- 対象: DxLib 3.24f / Direct3D 11 モード(DxLib の既定)/ シェーダーモデル 4.0(`vs_4_0` `ps_4_0`)
- 読者: 講師・上級の生徒(リファレンス層)と、授業を受ける生徒(授業層)の両方
- ビルドと実行: 05_VSCodeExtention の拡張機能(DxLib 開発環境)で開いて使う

## 構成

| フォルダ | 中身 | 層 |
|---|---|---|
| `spec/` | Direct3D 11 定数バッファ仕様書(D3D9 版リファレンスと同じ粒度) | リファレンス |
| `verify/` | 仕様書の各項目を描画で確かめるプログラム | リファレンス(根拠) |
| `reference/d3d9_original/` | 公式の Direct3D 9 版サンプルの原本(比較用。変更しない) | リファレンス |
| `samples/` | 公式サンプルの Direct3D 11 移植版と C++ サンプル(動作確認済みのものだけ) | リファレンス |
| `course/` | 授業用の順番と解説(samples から選んで並べる。`course/index.html` をブラウザで開く。図・画面写真付きの HTML) | 授業 |

## 移植する公式サンプル

「サンプル 20 本」と呼んでいたものの実体は下の A です(実際は 21 本)。B と C も公式の Direct3D 9 版サンプルなので、同じ方針で移植します。

- **A. 3D モデル描画の基本 21 本**(`help/program/dxprogram_3DModelShaderBase.html`)
  ライティング無し 4 / ディレクショナルライト 2 / ポイント・スポットライト 4 / フォンシェーディング 4 / トゥーン 5 / 法線マップ 2。
  モデルなどの素材は公式サイトの `https://dxlib.xsrv.jp/file/<名前>.zip`。
- **B. 応用サンプル 7 本**(`help/program/` 以下。SDK に .fx 同梱)
  深度シャドウ / 光学迷彩 / ポイントライトの深度シャドウ / 被写界深度 / フレネル反射 / 鏡 / 水面。
- **C. 関数リファレンスのサンプル 8 本**(`help/function/dxfunc_3d_shader.html`)
  頂点シェーダー / ピクセルシェーダー / 定数の設定 3 種 / 描画先の複数指定 / Indexed 版の描画 2 種(シェーダーは使い回し)。
  いちばん小さいので、仕様書の検証と授業の入口に使う。

## 決まりごと

- 動作確認できたものだけを `samples/` に置く。確認できなかったものは理由を書いて保留にする。
- 仕様書の記述には必ず根拠を付ける。ソースを読んだだけの推測は「推測」と書く。
- DxLib のヘッダーとシェーダー原本は CP932。ShaderCompiler.exe も CP932 のソースしか読めない。
- `reference/` の原本と DxLib 由来の素材は DxLib の作者の権利物。拡張機能の MIT ライセンスの対象外。
