DxLib 開発環境(VSCode 拡張機能)のインストール方法
==================================================

1. Visual Studio Code(VSCode)をインストールしておく。
     https://code.visualstudio.com/

2. このフォルダの「install.bat」をダブルクリックする。
     黒い画面が出て、「インストールが完了しました。」と出れば成功。

3. VSCode を開き直し、左端のバーに DxLib のアイコンが出ていることを確認する。


[注意] dxlib-devenv-〇〇.vsix を直接ダブルクリックしないでください。
       Visual Studio が入っている PC では、Visual Studio のインストーラーが
       起動して「Visual Studio Code にインストールしてみてください」と失敗します。
       必ず install.bat を使ってください。

うまくいかないとき
------------------
- 「Visual Studio Code が見つかりません」と出たら、VSCode を先にインストールしてください。
- 「インストールに失敗しました」と出たら、インターネットへの接続を確認してください。
- それでも解決しない場合は、黒い画面の内容を講師に見せてください。
