# セットアップ手順

## 1. Visual Studio Community を入れる

1. [ダウンロードページ](command:dxlib.openVsDownload)から Visual Studio Community のインストーラーを取得して実行します。
2. 「ワークロード」の一覧で **C++ によるデスクトップ開発** にチェックを入れます。
3. 右下の「インストール」を押します。しばらく時間がかかります。

Visual Studio が入っているのに DxLib パネルが「C++ によるデスクトップ開発 が未インストール」と出る場合は、パネルの **[ワークロードを追加]** を押してください。インストーラーが開き、「はい」を押すだけで追加されます。

## 2. DxLib SDK のフォルダを指定する

1. 配布された DxLib の zip を、好きな場所に展開します(例: `C:\DxLib\DxLib_VC`)。
2. DxLib パネルの SDK の行にある **[変更]** を押し、展開した中の **「プロジェクトに追加すべきファイル_VC用」** フォルダを選びます。
3. パネルにバージョン(例: 3.24f)が表示されれば完了です。

## 3. 最初のプロジェクトを作る

1. 左のアクティビティバーの DxLib アイコンを押してパネルを開きます。
2. **[新規プロジェクト作成]** を押し、プロジェクト名(英数字とアンダースコア)、作成先、テンプレートを選んで **[作成]** を押します。
3. 新しいフォルダが開くと、「このフォルダー内のファイルの作成者を信頼しますか?」と聞かれます。自分で作ったプロジェクトなので **[はい、作成者を信頼します]** を押します。
   - **「親フォルダー内のすべてのファイルの作成者を信頼します」にチェックを入れてから押す**と、同じ場所に作るプロジェクトでは次から聞かれません。
   - 「いいえ」を押したり閉じたりすると「制限モード」になり、ビルドや実行ができません。DxLib パネルの **[このフォルダを信頼する]** から、あとで信頼できます。
4. **F5** を押します。ビルドが走り、ウィンドウが表示されます。
